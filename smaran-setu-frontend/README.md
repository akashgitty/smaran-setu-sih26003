# Smaran Setu — SIH26003 Frontend

**Smaran Setu — Bridging Memories, Connecting Lives**

Frontend prototype for SIH26003. This project contains two access roles:

- User (elderly user)
- Caregiver

## Stack

React + Vite + JavaScript + Tailwind CSS + React Router + Lucide + Recharts + Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually `http://localhost:5173`.

## Demo login

The prototype does not need a real backend yet. Choose a role on the login page:

- User → `/user/home`
- Caregiver → `/caregiver/dashboard`

## Build for production

```bash
npm run build
```

## Important

This is a frontend prototype. Authentication, database, real AI models, secure medical data handling, and production APIs must be added before real-world deployment.
